# Tools

| Command | Ports | Output |
|---|---|---|
| `cwevent` | `cwevent.c` | one row per event (up to 164 columns) |
| `cwgame` | `cwgame.c` | one row per game |
| `cwdaily` | `cwdaily.c` | one row per player per game |
| `cwsub` | `cwsub.c` | one row per substitution |
| `cwcomment` | `cwcomment.c` | game comments |
| `cwbox` | `cwbox.c` | box scores (text, `-X` XML, `-S` SportsML) |

For options see Chadwick's [documentation](https://chadwick.readthedocs.io/).
